# Sales Data

A simple Python application for working with sales data. This project includes a script to process/analyze a sales dataset, along with its dependencies and sample data.

## 📂 Repository Contents

| File | Description |
|------|-------------|
| `app.py` | Main Python script for the sales data application. |
| `requirements.txt` | Python dependencies required to run the project. |
| `sales_data.csv` | Sample sales dataset used by the application. |
